## Description

TinyTrayMonitor は Windows のシステム トレイで PC の状態を表示します。8 つの小さな項目が、いま起きていることをすぐに教えてくれます。

- CPU 使用率
- メモリ使用率
- ネットワークのダウンロード
- ネットワークのアップロード
- GPU 使用率
- GPU VRAM 使用率
- ディスク使用率
- ディスク負荷

項目ごとに色分けされたトレイ アイコンが 1 つずつあるので、タスク マネージャーを開かなくても数値をひと目で読めます。

### 機能

- 独立した 8 つの項目。不要な項目はオフにできます。
- 計測するグラフィックス カード、ネットワーク アダプター、ドライブを選べます。
- ライト、ダーク、自動の設定ウィンドウ。
- 項目ごとの色、またはタスクバーのテーマ。
- 更新間隔は 1 秒から。
- 「サインイン時に実行」が既定でオンなので、再起動後もすぐに表示されます。設定でオフにできます。
- 仮想アダプター(VPN、Hyper-V スイッチ)を除外して、実際のネットワーク カードの数値だけを表示できます。
- 設定ウィンドウで項目をタスクバーにピン留めする方法を案内し、タスクバーの設定を開くボタンを用意しています。
- アカウント不要、テレメトリなし、通信なし。設定とログは PC の中だけに残ります。
- 小さくネイティブ。Win32 と GDI で作られ、Electron もバックグラウンド サービスもありません。

TinyTrayMonitor はオープン ソース(MIT)です。Microsoft Store 版は Windows のパッケージ ID とスタートアップ タスク API を使い、更新後もトレイの配置を保ちます。

Windows 10 バージョン 1809 以降が必要です。

## What's new (0.12.0)

- アプリのすべての部分で TinyTrayMonitor の名前を使うようになりました。サインイン時の起動項目も含みます。
- この更新のあとサインイン時に表示されなくなった場合は、設定で「サインイン時に実行」をもう一度オンにしてください。
