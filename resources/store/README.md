# Store assets

Assets for the Microsoft Store listing of **TinyTrayManager** (Partner Center → Store listing).

| File | Use |
| --- | --- |
| `StoreLogo300.png` | Store logo (300x300). Generated by `tools/make_assets.py`. |
| `screenshots/01-settings.png` | Settings window at 1:1 with the headline copy and a taskbar strip. |
| `screenshots/02-tray.png` | The six readouts, cropped from the live taskbar and enlarged, each with its label. |

Screenshots are 1920x1080 (16:9). Partner Center requires at least one screenshot of
1366x768 or larger.

Regenerate the logo with `python tools/make_assets.py`.

## Screenshots

Both screenshots are composed from a real capture of the running app, never drawn by hand:

1. Set `language = "en"` in `%APPDATA%\tray-monitor\config.toml` so the dialog matches the
   en-US listing.
2. `cargo build --release` and start `target\release\tray-monitor.exe --settings`.
3. `python tools/promote.py` promotes the six icons out of the tray overflow; restart the app
   afterwards so Windows picks the promotion up.
4. Capture the desktop at native resolution, then capture the dialog on its own with
   `PrintWindow` (`PW_RENDERFULLCONTENT`) so overlapping windows do not end up in the crop.
5. Crop the icons from the taskbar capture. At 100% scaling each readout occupies a 32x32
   cell and the cells sit about 31px apart; the taskbar background is keyed out so the cells
   blend into the composed background.
6. Enlarge with nearest-neighbour only. The icons are drawn with a 1-bit pixel font, so any
   smooth interpolation blurs them.

Re-capture after a visible UI change, and keep the `v<version>` label in the dialog in sync
with `Cargo.toml` — it is visible in `01-settings.png`.
