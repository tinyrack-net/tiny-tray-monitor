# Store assets

Assets for the Microsoft Store listing of **TinyTrayManager** (Partner Center → Store listing).

| File | Use |
| --- | --- |
| `StoreLogo300.png` | Store logo (300x300). Generated by `tools/make_assets.py`. |
| `screenshots/01-settings.png` | Settings window with the tray readouts below. |
| `screenshots/02-tray.png` | The four readouts, enlarged. |

Screenshots are 1920x1080 (16:9). Partner Center requires at least one screenshot of
1366x768 or larger.

Regenerate the logo with `python tools/make_assets.py`. Screenshots are captured from a
running build and composed; re-capture them after a visible UI change.
